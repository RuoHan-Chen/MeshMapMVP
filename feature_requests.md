# MeshMapMVP Feature Requests

## Feature Specifications

### 1. Add timestamp for locations and events
- Display timestamps on the map to indicate how recent claimed locations and events are
- Helps users understand the recency of map data

### 2. 5km placing event label max
- Maximum distance of 5 kilometers for placing event labels
- Ensures labels are placed within reasonable proximity to user location

### 3. 3 Types of events
- Users can set custom name and description for three event types:
  - **Hazard** - Danger or risk indicators
  - **Help** - Assistance or support requests  
  - **Other** - Miscellaneous event categories

### 4. Event delete button on local device
- Provide a delete button for events on the local device
- Allows users to remove events they no longer need

### 5. Messages and events expiration
- **Messages**: Expire by default after 20 minutes
- **Events**: Expire by default after 1 hour
- Automatic cleanup to maintain map relevance

### 6. Color gradient on event based on engagement
- Events display a color gradient that changes based on user engagement
- Visual indication of event popularity or interaction levels

### 7. Button to recenter map on location
- Provide a button to recenter the map to the user's current location
- Quick navigation back to user's position
